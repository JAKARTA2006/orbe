# Controles, parâmetros e presets

## Botões

| Botão | Ação |
|---|---|
| **Cima / Baixo** | escolher parâmetro no painel (segure para repetir) |
| **Esq / Dir** | ajustar o parâmetro selecionado (segure para repetir) |
| **Analógico direito** (horizontal) | ajuste fino e contínuo do parâmetro selecionado |
| **Analógico esquerdo** | inclina a gravidade do anel: as bolas "caem" para onde você aponta |
| **A** | chacoalhar: dá um empurrão aleatório em todas as bolas |
| **B** | nova cena: sorteia timbre, número de bolas, texturas e às vezes a escala |
| **X** | congelar os grãos: o buffer de grãos para de gravar e fica repetindo o que já tinha |
| **Y** | próximo preset |
| **L1 / R1** | tônica um semitom abaixo/acima |
| **L2 / R2** (ou **L3 / R3**) | escala anterior/próxima |
| **START** | tocar / pausar (com fade suave) |
| **SELECT** | mostra ou esconde a ajuda |
| **SELECT + START** | sair, salvando as configurações |

## Tela

- **Anel** (à esquerda): cada segmento colorido é uma nota da escala. A volta inteira cobre duas oitavas, e o risco branco marca a tônica. O segmento acende quando uma bola bate nele.
- **Letra grande no centro**: a tônica atual. Use a mesma tônica no seu instrumento.
- **Painel** (à direita): preset, tônica, escala, osciloscópio, VU e parâmetros.
- **Rodapé do painel**: carga de CPU do áudio, taxa de amostragem, JIT, modo leve e quadros por segundo.

## Parâmetros

| Parâmetro | Faixa | O que faz |
|---|---|---|
| **TIMBRE** | SINO, VIDRO, CORDA, SOPRO | Som das notas, todos em síntese FM. **SINO**: metálico e inarmônico. **VIDRO**: brilhante e curto. **CORDA**: ataque de dedilhado. **SOPRO**: ataque lento, tipo pad. |
| **BOLAS** | 1 a 8 | Número de bolas, ou seja, a densidade de notas |
| **VELOCIDADE** | 0 a 100% | Velocidade das bolas |
| **GRAVIDADE** | 0 a 100% | Puxa as bolas para baixo e cria arcos e padrões repetitivos |
| **GIRO** | 0 a 100% | Velocidade de rotação do anel, que faz a melodia "derivar" |
| **OITAVA** | 2 a 5 | Oitava base das notas |
| **DECAY** | 0 a 100% | Duração das notas, de cerca de 1 s a 8 s |
| **DRONE** | 0 a 100% | Volume do drone grave (tônica, quinta e oitava), com filtro que abre junto |
| **GRAOS** | 0 a 100% | Nuvem granular: pedaços dos últimos 3 s de som, inclusive uma oitava acima e abaixo |
| **FITA** | 0 a 100% | Wow, flutter, chiado, saturação e perda de agudos, como uma fita gasta |
| **ECO** | 0 a 100% | Eco *ping-pong* estéreo (mais volume e mais repetições) |
| **ESPACO** | 0 a 100% | Tamanho e volume do reverb |
| **SHIMMER** | 0 a 100% | Realimentação do reverb uma oitava acima, que dá um brilho "celestial" |
| **VOLUME** | 0 a 100% | Volume geral |

## Escalas

| Nome | Intervalos | Clima |
|---|---|---|
| MENOR | 0 2 3 5 7 8 10 | melancólico |
| DORICO | 0 2 3 5 7 9 10 | menor com a 6ª maior, mais aberto |
| FRIGIO | 0 1 3 5 7 8 10 | desértico, tenso ("Duna") |
| LIDIO | 0 2 4 6 7 9 11 | flutuante, sonhador |
| MAIOR | 0 2 4 5 7 9 11 | luminoso |
| PENTA | 0 3 5 7 10 | pentatônica menor, nunca soa "errada" |
| HIRAJOSHI | 0 2 3 7 8 | japonesa, contemplativa |

## Presets

| Preset | Timbre | Escala / tônica | Ideia |
|---|---|---|---|
| **ORBIX** | SINO | PENTA / D | sinos com shimmer, o som de referência |
| **DUNA** | CORDA | FRIGIO / D | cordas graves, gravidade, drone forte |
| **BLADE RUNNER** | SOPRO | MENOR / A | pads lentos, fita e eco longos |
| **CRISTAL** | VIDRO | LIDIO / E | notas rápidas e agudas, shimmer alto |
| **FITA VELHA** | SINO | PENTA / G | fita bem gasta e muitos grãos |
| **OCEANO** | SOPRO | HIRAJOSHI / C | 6 bolas lentas sob gravidade, reverb enorme |

Ao escolher um preset, ele também define a tônica e a escala. Depois disso, você pode mudar livremente com L1/R1 e L2/R2.

## Dicas para tocar junto

- Ajuste a tônica do ORBE para a tônica da música. **PENTA** e **HIRAJOSHI** são as escalas mais seguras para improvisar por cima.
- Para fundo de solo, use **BOLAS** baixo (1 ou 2), **DECAY** alto e **ESPACO** alto.
- **X** (congelar grãos) segura uma "cama" estável enquanto você toca.
- **START** faz fade out e fade in, o que serve para terminar uma música.
